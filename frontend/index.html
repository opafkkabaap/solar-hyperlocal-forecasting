Executive Overview

Project Summary & Mission

La Trobe University · UniSolar

The Helios Solar Intelligence System provides high-accuracy 1-hour-ahead weather forecasting, physics-informed PV power prediction, and dispatch optimization for solar installations across Victoria, Australia.

Physics-Informed Architecture

Integrates astronomical solar position (zenith, elevation, azimuth) and Ineichen clear-sky radiation curves with XGBoost and PyTorch Deep Bi-GRU sequential models.

Multi-Campus Synchronization

Harmonizes 5 Victorian campuses (Bundoora, Wodonga, Bendigo, Mildura, Shepparton), converting UTC irradiance records to local Eastern Time to align with generation intervals.

Actionable Energy Optimization

Determines optimal panel tilt, attributes thermodynamic losses (cell heating, cloud cover, inverter clipping), and schedules battery storage to shave peak grid demand.

Clear-Sky Index Normalization
k_t = GHI / GHI_clearsky

Normalizes solar radiation against the cloudless physical envelope, removing diurnal cycles from the regression model.

Faiman PV Cell Temperature
T_cell = T_air + GHI / (u_0 + u_1 · W_s)

Models module temperature rise as a function of ambient temperature, irradiance, and wind speed cooling.

Temperature-Derated DC Power
P_ideal = kWp · (GHI/1000) · [1 - 0.0038(T_cell - 25)]

Quantifies silicon crystalline temperature coefficient derating (-0.38%/°C) above standard test condition.

Forecast Skill Score
SS = (1 - RMSE_model / RMSE_persistence) × 100%

Evaluates percentage accuracy advantage over standard 24-hour diurnal seasonal persistence baseline.

Illustrative Power Flow & Battery State-of-Charge Schedule (48h Window)

How Predictive Dispatch Works in optimizer.py:

  1. Pass 1 (Solar Capture): Whenever forecasted solar generation exceeds campus load ($P_{\text{solar}} > P_{\text{load}}$), surplus power charges the battery up to the 95% maximum state-of-charge buffer.
  2. Pass 2 (Binary Search Peak Shaving): Using the forecasted generation curve, a binary search finds the optimal flat threshold to discharge stored solar during demand peaks, which reduces peak demand by 24.1%.
